# Warning Label for Humans: One Line, Big Laugh

One single-line safety warning label for human beings, 160 characters or fewer,
funny first and plausible second. `main.py` writes the line to
`$OUTPUT_DIR/entry.txt` (default `/output`).

Run:

```
OUTPUT_DIR=/tmp/o python3 main.py
```
